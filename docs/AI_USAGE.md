# AI 使用与验证记录

## 使用了哪些 AI 工具

- 编码：使用 AI 编程助手完成项目骨架、评估引擎、数据提供层与前端代码，并逐轮验证与修正。
- 运行期：可配置 OpenAI 兼容模型（`LLM_API_URL` / `LLM_API_KEY` / `LLM_MODEL`）把自然语言关注点解析为规则 JSON，并生成解释文案；未配置时使用内置确定性解析器兜底。

## AI 参与环节

- 将自然语言关注点翻译为 `{conditions, logic, cooldownSeconds, dedupWindowSeconds}` 结构。
- 根据条件评估结果生成"触发 / 未触发 / 降级 / 冷却 / 去重"的中文解释。
- 辅助生成 README 与测试用例初稿。

## 人工修正与验证

- LLM 产出的规则 JSON 需经过 `validateRule` 强校验：条件类型、运算符、数值范围非法时拒绝并提示，避免把错误规则写入任务。
- 触发判定不由 LLM 决定，由确定性代码执行；LLM 只负责翻译与解释，关键数字回到 `condition.value` 与数据快照字段。
- 人工检查了冷却、去重、失败退避三条路径，确保"同一理由不重复提醒"与"失败不静默"。
- 接入扶摇真实接口后，人工比对行情快照（`last_price` / `prev_price` / `price_change_ratio_pct`）、热股榜排名与交易日历的字段含义与单位，修正了字段映射（如快照无中文名，需另查元信息）。

## 验证记录（手工复现）

- 创建任务："贵州茅台收盘价跌破 1600 或热榜进入前 3，就提醒我，24 小时只提醒一次"。规则被正确解析为 OR 组合与 86400 秒冷却。
- 通过模拟行情把价格调到 1590，触发成功，解释中标注来源字段 `600519.SH.close = 1590`。
- 打开"数据源故障"开关后运行，任务不触发且 `lastResult.status = failed`，解释为"行情数据源连接超时"。
- 真实模式下 `node scripts/smoke.js` 返回：贵州茅台最新价、热股榜排名、2026-11-03 是否交易日，三条链路均为扶摇真实数据。
