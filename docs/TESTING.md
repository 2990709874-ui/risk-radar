# 测试说明

## 运行

```bash
npm test
```

另有真实数据源冒烟测试：

```bash
node scripts/smoke.js
```

## 覆盖场景

### 主链路

- 自然语言（兜底解析器）到规则：`茅台跌破1600` → `price` 条件。
- 从结构化规则直接创建任务。
- 规则修改产生新版本，并保留历史版本。
- 触发后写入触发历史，且带解释。
- 同一触发理由在去重窗口内只记录一次（`deduped`）。
- 触发后进入冷却期，冷却结束前不重复触发（`cooldown`）。
- 数据源故障后自动恢复（失败 → 重试 → 恢复为运行中）。

### 数据 / 接口异常

- 行情数据缺失：条件状态为 `missing`，不触发，解释说明缺失字段。
- 数据源故障（模拟）：任务状态变为 `failed`，不静默触发。
- 过期数据（模拟）：条件状态为 `stale`，结果降级并说明。
- 真实接口错误码（如 `code=2001` 未认证、`code=4001` 限流、`code=5003` 数据源不可用）会转成带原因的降级说明，不静默通过。

### 合规边界

- 规则校验拒绝未知运算符与未知条件类型。
- 解释文案不含涨跌预测与买卖建议。
- LLM 输出只用于规则翻译，触发判定由代码决定。

### 数据模式

- 单元测试与端到端测试均在「演示（mock）」模式下运行，保证离线可重复。
- 真实模式通过 `node scripts/smoke.js` 手动验证行情、热榜、交易日历三条链路。
